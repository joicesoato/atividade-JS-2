# Pizzaria - Atividade 2

## Descrição
Nesta atividade foi criado um modal dinâmico para exibir o resumo completo do pedido antes da finalização.

O modal apresenta:
- Lista de pizzas
- Quantidade total
- Soma final
- Botão de confirmar pedido
- Botão de fechar modal

---

## Funcionalidades

- Modal estilizado
- Overlay escurecido
- Abertura e fechamento do modal
- Dados preenchidos dinamicamente com JavaScript
- Confirmação do pedido

---

## Tecnologias Utilizadas

- HTML5
- CSS3
- JavaScript

---
